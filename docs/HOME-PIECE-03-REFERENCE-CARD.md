# HOME / PIECE 03 — Reference Card

## Status
ACTIVE — third Home content piece only.

## Primary real-world reference
Hershesons — Stores / Fitzrovia
https://www.hershesons.com/pages/stores

The live page was inspected directly before implementation.

## Real design characteristics observed
First substantial image-led salon block:
- pure white background;
- wide salon-interior image used as the visual anchor;
- two-column composition on desktop;
- image on the left, compact copy block on the right;
- bold uppercase sans-serif heading;
- generous spacing between heading, description and supporting action;
- minimal decoration;
- black/white contrast;
- visual emphasis comes from the real interior photography, not effects.

## What SEZIONE adapts
- two-column image/text composition;
- real salon-interior photography as the primary visual;
- white background;
- bold uppercase sans-serif headline;
- restrained copy width;
- generous negative space;
- simple rule/microcopy instead of decorative UI.

## What SEZIONE does NOT copy
- Hershesons name, logo or wording;
- exact layout measurements;
- exact CTA styling;
- exact salon claims;
- exact typography;
- exact image crop.
